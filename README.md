# Complete English — 150-day Fluency Lab

## About this project

Complete English is a free collection of interactive exercises for practising everyday and professional English. The focus is on **using language actively**: recognising useful sentence patterns, substituting parts of a complete sentence, retrieving expressions in context, and communicating an idea clearly.

The 150-day learning routine began as a personal software project and is being shared publicly so others can explore or adapt the exercises to their own goals. Some lessons include software engineering scenarios, while the [public starter exercise](start.html) uses everyday situations.

**A note about the material:** I'm a software engineer, not an English teacher. I'm sharing techniques and exercises I'm experimenting with in my own routine, not offering a certified course, a scientifically validated method, or a guarantee of fluency.

### Try it in 12 minutes

Start with the [interactive speaking demo](start.html) (published as [Start Here](https://alextgtome.github.io/complete-english/start.html) when GitHub Pages has deployed). It includes:
- three natural sentence chunks with concise Portuguese explanations;
- two cumulative substitution drills with every cue provided;
- a recovery exercise for continuing when you cannot remember a word.

Then try the [lesson archive](index.html) and practise speaking with any voice-enabled AI assistant or your own phone recorder. Availability and behaviour differ between providers. No login or microphone permissions are needed on the site. Your typed practice and checkmarks stay in your own browser, not on a central server.

## For contributors and maintainers

The curriculum and automation rules are versioned in [Course Specification](docs/COURSE_SPEC.md), [Daily Publishing Runbook](docs/DAILY_RUNBOOK.md), and [course.config.json](course.config.json). These documents are the source of truth for the scheduled lesson generator.

The scheduled agent uses a **tiny [lesson manifest](data/lesson-manifest.json)** to check whether the requested day already exists. Lessons are also archived as separate, categorized metadata files in `data/lesson-records/everyday/`, `data/lesson-records/workplace/`, and `data/lesson-records/interview/` (historical categories reflect each original lesson's actual content). The existing HTML lesson links are unchanged. For creating a *new* lesson, the agent uses a compact [generation index](data/generation-index.json) (all prior chunk phrases and first-use dates, all lesson topics and seven recent lessons) instead of loading the full [lesson registry](data/lessons.js) during planning. The full registry is read only when applying an update. The index is **derived**, generated by [build-generation-index.mjs](scripts/build-generation-index.mjs), and kept in sync by the quality gate.

The automated quality gate runs the [lesson validator](scripts/validate-lessons.mjs), checks the generation index and checks shared JavaScript syntax **before** deploying to GitHub Pages:

    node --check assets/app.js
    node scripts/build-generation-index.mjs --check
    node scripts/build-lesson-catalog.mjs --check
    node scripts/validate-lessons.mjs

It checks lesson chronology, first-use chunk IDs, duplicate phrases, HTML references, cumulative substitution cues and several known grammar regression patterns. These tests are not a substitute for editorial review: natural idiomatic English and scenario quality still require careful inspection.

## Pages publishing

This repository includes `.github/workflows/pages.yml`, configured to deploy the static site from the `develop` branch after each push. In GitHub repository Settings → Pages, select **GitHub Actions** as the build/deployment source. Then check **Actions → Publish Complete English site** for the deployment result. The site address is `https://alextgtome.github.io/complete-english/` once GitHub Pages reports a successful deployment.
